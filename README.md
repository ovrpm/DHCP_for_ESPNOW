# Lightweight DHCP-style addressing for ESP-NOW
This project is a DHCP-style IoT addressing system for ESP-32 devices using the ESP-NOW protocol. 
Devices discover a Registrar node, request an NID, receive a lease, renew it, and release it on exit. 
Pre-Shared Keys are used for authentication.
